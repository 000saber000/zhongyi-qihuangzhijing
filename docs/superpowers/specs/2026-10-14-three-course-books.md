# 学习路径实体三维古籍

用户明确要求真正 3D 古籍，不接受 CSS 卡片贴图。将三条既有课程路径展示为三本较新、完整的线装古籍，环绕小型中医星云慢速公转。真实实体封面、书脊、页层、订线使用 Three.js 网格与光照；图像仅作为布面材质。依次进入、悬停柔光与暂停、键盘暂停、点击三维翻开再进入既有学习窗口、完成后更新节点与进度，关闭恢复公转。减少动态效果时停止公转、直接打开学习；手机保留固定选课按钮。

主页知识星云的相机、点击、拖动、缩放、时钟和右侧面板不改变。AI、学习进度、典籍管理、收藏及最新主分支的知识入口效果沿用原实现。动态场景失败时仍可学习。按既有授权完成审查、必要测试、兼容导出、主分支发布和 Render 核验。
