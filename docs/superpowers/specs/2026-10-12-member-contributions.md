# 典籍成员贡献

使用现有本站账号和管理员权限。游客可阅读已发布典籍的评论，登录成员可评论、提交正文/简介/出处/学习要点的修改建议。评论为纯文本，最多2000字符，管理员可隐藏；建议须附理由，最多2000字符。

成员建议独立存储，保存原字段快照和建议字段，不修改公开典籍。站内典籍管理提供待审核列表及待处理数量；成员书斋展示自己的建议和审核结果。外部通知不在本次范围内。

用户已选择：管理员采纳后只合并到草稿，预览确认后手动发布。复用现有发布功能。管理员审核时使用事务及行锁，防止重复审核；只有原字段仍与草稿一致时才允许合并，其他字段不受影响。同字段冲突提示管理员，绝不自动覆盖。拒绝可附处理说明。

复用 GitHub jsdiff 的 npm 包 `diff` 展示按字符的修改差异，保留许可证。账号状态、管理员权限和临时密码限制均在服务端验证。评论及建议分页读取；评论/建议提交按账号限流。旧账号删除后保留作者名称和贡献记录。

本次包含迁移、API、成员界面、管理员审核界面、自动测试、兼容 Render 的发布产物及上线确认。实际前端部署发布 public/，必须执行 release:build。
