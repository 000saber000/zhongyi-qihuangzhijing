# 经络云图 · 青玉透视版

用户已确认按山水、青玉人体与透视模式概念图直接修改现有页面，并要求背景采用同样的视觉方向。此文记录本次实施范围；不重新执行已完成的许可或导航任务。

## 页面与交互

- 仅经络云图采用墨绿山水湖面背景、金色罗盘与青玉人体；保留共享导航的位置。
- 页面保留一个可旋转的人体，使用男性、女性按钮切换。概念图中的左右人体用于模式对照，不改成同时渲染两个人体。
- 细化躯干、手足与面部，采用更自然的垂臂姿态和抛光青玉材质。
- 穴位采用可见的柔光、光环与浮动粒子。悬停显示名称、标准编号及侧别；点击继续使用已有镜头定位和知识面板。
- 人体透视默认关闭；开启后显示内脏、经脉两个独立图层，人体不透明度初值 25%，范围 8–65%。切换人体或穴位保留透视设置。
- 内脏为原创建模的空间结构示意，包含心、肺、肝、胃、肠、肾等；经脉为主要体表关系示意，不宣称完整分支或临床精确定位。
- 手机保留目录抽屉、视角按钮和可展开知识面板。无 WebGL 时保留静态学习，并禁用不可显示的透视开关。

## 实现边界

沿用现有 React / R3F 场景、知识目录、收藏和相机系统，不增加账户、后台或数据库接口。模型更新到 v2，并重新投影两版各 34 个点位、同步文件摘要及相机视线检查。人体模型来自现有固定版本的 MPFB CC0 基底；背景由图像工具生成，内脏及线路由本项目脚本制作，保留 Blender 源文件。

当前环境的 Lux3D 主技能可以读取，但生产总览与本地运行时不可用，也没有已就绪的 Lux3D 凭据。未提交任何付费 Lux3D 任务；采用已有资产与本地 Blender 路径完成模型制作。

资源按当前页面和所选模型加载；内脏 GLB 在首次开启内脏层时请求。内脏失败不影响人体、经脉和知识阅读，可以独立重试。粒子使用共享纹理，隐藏页面或启用减少动态效果时停止主动刷新。

## 验证与交付

检查实际桌面 / 手机画面、悬停与点击、透视图层、模型切换保留状态、图层下载失败重试、WebGL 降级、男女点位与摘要、主导航稳定性，并运行浏览器回归和两个生产输出的测试。验证记录见 `docs/meridian-immersive-validation.md`。
