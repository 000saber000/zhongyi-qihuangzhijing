# 账号管理验证记录（2026-10-11）

管理功能沿用现有网站、API 和 PostgreSQL；管理员权限由数据库决定，浏览器保存的角色不能授予权限。启动配置只提升指定的已有账号，不创建管理员账号，也不在注册时授予权限。

## 已完成验证

- 后端 TypeScript 检查通过；独立 PostgreSQL 集成测试 **21/21** 通过。
- 浏览器完整回归 **30/30** 通过，包含原有游客记录、双设备同步、导入、失败重试、知识星海、手机布局与新增管理流程。
- 生产构建和单文件导出通过，包含现有公开 API 地址；手机 390×844 的单文件管理入口、管理员保护提示和页面宽度检查通过。
- 本地单文件验证使用独立测试 schema；生产 API 地址在网络发送前被拦截并转至本地测试服务，未访问线上账号数据。测试子进程和临时 schema 已清理。

后端测试覆盖普通用户越权、伪造注册角色、仅提升已有账号、字面用户名搜索与分页、禁用/恢复、全部会话撤销、密码重置后强制修改、替换密码会话、管理员保护、删除级联、审计失败回滚，以及密码重置与旧密码登录同时发生的情况。管理列表和审计记录不返回密码摘要或会话令牌。

浏览器测试覆盖管理确认流程、一次性临时密码不写入浏览器存储、退出后迟到响应不显示临时密码、修改密码后的存储失败提示，以及恢复身份失败后重新验证。

## 代码复核及修复

一次独立完整分支复核发现：密码修改已在服务器完成、响应仍在传输时，后台刷新可能使用旧令牌返回 401，误使当前浏览器退出。按实际用户影响将其作为发布前必须修复的问题处理；先复现失败，再验证修复。两项测试分别覆盖新触发的刷新和已在等待的刷新，均完成 RED→GREEN，修复后的完整回归 30/30 通过。

修改密码时暂停新刷新、使旧读取失效，并等待已有写入完成；成功后安装替换会话再恢复读取。管理员账号继续受到保护。

## 发布验证边界

沿用用户已授权的 main 发布流程，不再重复要求方案或发布确认。云端技能脚本未作为本地可执行文件安装，验证步骤与命令结果采用手工记录；这些记录需手动维护。

线上发布通过 Render 的同一提交号 Live 状态及 `Configured administrator ready`、API 监听启动日志确认。当前环境限制直接访问线上 HTTP，因此不宣称逐项实测线上管理操作；验证不对真实用户执行禁用、重置密码或删除操作。生成的压缩 HTML 通过生产导出和本地单文件检查验证。
