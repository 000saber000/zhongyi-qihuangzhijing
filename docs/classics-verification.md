# 典籍管理验证记录

新增管理员典籍编辑功能，复用现有账号角色与密码管理。典籍入口为 `/#classics`，账号管理继续使用 `/#admin`。数据库第三版迁移将内置知识与导读导入草稿、发布快照，不覆盖已有账号、收藏或学习进度。

## 已验证

- `npm --prefix server run check` 通过。
- 独立 PostgreSQL 数据库：API 完整测试 25/25 通过，包含现有账号管理、草稿隔离、发布、新典籍收藏/导入、编号及关系验证、版本冲突和迁移幂等。
- `npm test` 完整浏览器回归 36/36 通过，包含双设备同步、账号管理、密码重置、星海、手机布局和典籍管理。
- 随后新增的“编辑冲突后重新登录”回归：先复现失败，修复后单独运行通过。浏览器验证共 37 项通过。
- 使用公开 API 地址进行生产构建和单文件导出，通过 TypeScript、Vite 和差异空白检查。
- 使用实际导出的 HTML 在本地验证管理员身份、典籍表单、未保存草稿禁止发布、手机 390×844 布局及无页面异常。生产 API 在网络发送前拦截并转发到独立本地测试 API，未操作线上账号或内容。

## 独立审查

两轮审查发现并修复四个问题：空学习要点覆盖默认导读、星海首页缺少同步失败重试、登录过期丢失输入、登录恢复后丢失编辑冲突重新载入入口。对应浏览器回归均通过。

同步主分支并行更新的账号管理与密码重置功能，复用 `role`、`sessionToken` 和现有 `INITIAL_ADMIN_USERNAME`，保留已经配置的 `aidejiasinuo` 管理员。

## 发布检查边界

上线使用现有 main 自动发布流程；通过 Render 确认网站/API 的部署提交及 Live 状态和管理员初始化日志。当前环境的外部网络策略不包含线上 onrender.com HTTP 地址，数据库也不允许外部连接，因此不声称已经逐项实测线上登录和编辑，不对真实用户执行测试写入。
